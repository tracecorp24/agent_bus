# AGENT BUS

Claude Code'un (üst yapay zekâ) CLI üzerinden çok sayıda Antigravity (`agy`) ajanını
ortak ve kalıcı bir otobüs üzerinden yönettiği sistem. Kesintiye dayanıklıdır, ortak durum
izlenir ve tüm ajanlar tek terminal ekranında gömülü görünür.

Durum: **planlama** — kod henüz yok.
